# Un loc mai sus

Aplicație web pentru telefon. Citește dintr-o captură a unui clasament de pași câți pași îți lipsesc până la locul următor, apoi generează trasee circulare pe jos, de lungimea potrivită, din locul în care ești.

Proiect personal, neafiliat Walk15.

## Date

- Captura este citită în browser și nu este păstrată.
- Totalurile și numele tău din clasament rămân în browserul telefonului.
- Locul de plecare și punctele traseului ajung la serverul de rutare [FOSSGIS](https://routing.openstreetmap.de/about.html).
- Harta vine de la [OpenStreetMap](https://www.openstreetmap.org/copyright).
